# Nano App Store

Welkom bij de **Nano App Store**, een platform dat je via de command line kunt gebruiken om eenvoudige spellen te spelen. Deze App Store bevat twee spellen:

- Raad-het-nummer
- Galgje

## Inhoud

- **app_store.py**: Het hoofdprogramma dat het keuzemenu bevat om de spellen te starten.
- **nummer_raadspel.py**: Het nummer raadspel, waarin de gebruiker een willekeurig getal moet raden binnen een bepaald aantal pogingen.
- **galgje.py**: Het galgje-spel, waarin de gebruiker letters moet raden om een willekeurig woord te raden.
- **woorden.json**: Een JSON-bestand met een lijst van woorden voor het galgje-spel.

## Gebruik

Open de terminal en voer het volgende commando uit om de Nano App Store te starten:

`python app_store.py`

- **Optie 1**: Raad-het-nummer spelen.
- **Optie 2**: Galgje spelen.
- **Optie 3**: Het programma afsluiten.
